# Power BI Project: Get Data from Online Services

## Project Overview

This project demonstrates how to connect Power BI Desktop to data generated by online applications such as:

- SharePoint Online
- OneDrive
- Dynamics 365
- Google Analytics
- Other Cloud-Based Services

Organizations use many online services to manage daily business operations. These applications generate valuable business data that can be connected to Power BI for reporting and analysis.

This project focuses on connecting Power BI to a **SharePoint Online List**, which is one of the most common online service data sources used in organizations.

---

# Learning Objectives

After completing this project, I was able to:

- Understand what Online Services are
- Connect Power BI to SharePoint Online
- Authorize cloud service connections
- Import SharePoint Lists
- Use Navigator to select online data
- Load or transform online service data
- Combine online data with other business datasets

# What URL Should Be Used?

Use:

```text
Site URL
```

Example:

```text
https://company.sharepoint.com/sites/Sales
```

---

# What Should NOT Be Used?

Avoid using:

```text
https://company.sharepoint.com/sites/Sales/Lists/SalesGoals
```

Power BI only needs:

```text
https://company.sharepoint.com/sites/Sales
```
